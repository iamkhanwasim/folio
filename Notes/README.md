# Notes Folder

This folder contains handwritten notes images used as input for article generation.

## Naming Convention
- Use descriptive names: `topic-name_notes.jpeg`
- Examples:
  - `desc_vs_infer_stat_notes.jpeg`
  - `gradient-descent_notes.jpeg`
  - `linear-regression_notes.png`

## Supported Formats
- JPEG (.jpeg, .jpg)
- PNG (.png)

## Workflow
1. Add your handwritten notes image here
2. Use the trigger command:
   ```
   Create article:
   - Folder: articles/statistics
   - Topic: Descriptive and Inferential Statistics
   - Date: Sep 2020
   - Notes: Notes/desc_vs_infer_stat_notes.jpeg
   ```
3. Claude Code will read the notes and generate the article
