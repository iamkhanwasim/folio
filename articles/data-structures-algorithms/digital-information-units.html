Fundamentals of Units of Digital Information

March 2020

Digital information is measured in units based on the binary number system. Understanding these units is fundamental to programming, as they determine how much memory your programs use and how efficiently data is stored and processed.

Every piece of data in a computer - numbers, text, images, programs - is ultimately represented as a sequence of bits. These units scale from the smallest bit to massive storage capacities.

The Bit: The Foundation

A bit (binary digit) is the smallest unit of digital information. It can hold only two values: 0 or 1.

Everything in computing boils down to bits. A bit represents:

  • On or Off
  • True or False
  • Yes or No
  • High voltage or Low voltage (at the hardware level)

The Byte: Building Block of Storage

A byte is a group of 8 bits. It is the standard unit for measuring storage and memory.

1 byte = 8 bits

With 8 bits, a byte can represent 28 = 256 different values (0-255).

# A byte can store a single character in ASCII
character = 'A'  # ASCII value: 65 (binary: 01000001)

# Python's bytes type
data = bytes([65, 66, 67])  # b'ABC'
print(data)

# Check size in bytes
text = "Hello"
print(len(text.encode('utf-8')))  # 5 bytes

Storage Units Hierarchy

Storage units scale in powers of 1024 (210) in the binary system, though decimal (powers of 1000) is sometimes used.

Unit Abbreviation Binary (Base 2) Decimal (Base 10) In Bytes
Bit b 1 bit 1 bit 1/8 byte
Byte B 8 bits 8 bits 1 byte
Kilobyte KB 210 = 1,024 bytes 103 = 1,000 bytes ~1,000 bytes
Megabyte MB 220 = 1,048,576 bytes 106 = 1,000,000 bytes ~1 million bytes
Gigabyte GB 230 = 1,073,741,824 bytes 109 = 1,000,000,000 bytes ~1 billion bytes
Terabyte TB 240 bytes 1012 bytes ~1 trillion bytes

Binary vs Decimal Units

The Confusion: Storage manufacturers use decimal (base 10) while computers use binary (base 2).

  • 1 KB (decimal) = 1,000 bytes
  • 1 KiB (binary) = 1,024 bytes
  • 1 GB (decimal) = 1,000,000,000 bytes
  • 1 GiB (binary) = 1,073,741,824 bytes

This is why a "500 GB" hard drive shows as ~465 GB in your operating system.

Conversions in Python

# Unit conversion functions
def bytes_to_kb(bytes_val):
    return bytes_val / 1024

def bytes_to_mb(bytes_val):
    return bytes_val / (1024 ** 2)

def bytes_to_gb(bytes_val):
    return bytes_val / (1024 ** 3)

# Example
file_size = 5242880  # bytes
print(f"Size: {bytes_to_mb(file_size):.2f} MB")  # 5.00 MB

# Human-readable file sizes
def human_readable_size(bytes_val):
    for unit in ['B', 'KB', 'MB', 'GB', 'TB']:
        if bytes_val < 1024.0:
            return f"{bytes_val:.2f} {unit}"
        bytes_val /= 1024.0
    return f"{bytes_val:.2f} TB"

print(human_readable_size(1234567890))  # 1.15 GB

Memory Usage in Python

Different Python data types consume different amounts of memory:

import sys

# Check object size in bytes
integer = 42
print(f"int: {sys.getsizeof(integer)} bytes")      # 28 bytes

text = "Hello"
print(f"str: {sys.getsizeof(text)} bytes")        # 54 bytes

numbers = [1, 2, 3, 4, 5]
print(f"list: {sys.getsizeof(numbers)} bytes")    # 104 bytes

data = {'a': 1, 'b': 2}
print(f"dict: {sys.getsizeof(data)} bytes")      # 232 bytes

# Large list memory usage
big_list = list(range(1000000))
size_mb = sys.getsizeof(big_list) / (1024 ** 2)
print(f"1M integers: {size_mb:.2f} MB")        # ~7.63 MB

Practical Examples

File Sizes:

  • Plain text file (1 page): ~2-5 KB
  • High-resolution photo: 3-10 MB
  • MP3 song (4 minutes): ~4 MB
  • HD movie (2 hours): 4-8 GB
  • Operating system: 10-50 GB

Working with Files in Python

import os

# Get file size
file_path = "example.txt"
file_size = os.path.getsize(file_path)
print(f"File size: {human_readable_size(file_size)}")

# Read file in chunks (for large files)
chunk_size = 1024 * 1024  # 1 MB chunks
with open("large_file.dat", "rb") as f:
    while True:
        chunk = f.read(chunk_size)
        if not chunk:
            break
        # Process chunk
        print(f"Read {len(chunk)} bytes")

# Calculate download time
file_size_mb = 500  # MB
download_speed_mbps = 50  # Megabits per second

# Convert Mbps to MB/s (divide by 8)
download_speed_mbs = download_speed_mbps / 8
time_seconds = file_size_mb / download_speed_mbs
print(f"Download time: {time_seconds:.0f} seconds")

Bits vs Bytes: Network Speeds

Important distinction:

  • Network speeds use bits per second (bps): 100 Mbps internet
  • File sizes use bytes: 500 MB download
  • Conversion: Divide bits by 8 to get bytes

100 Mbps internet = 12.5 MB/s actual download speed

Memory Optimization Tips

For efficient Python programs:

  • Use generators instead of lists for large datasets (saves memory)
  • Choose appropriate data types (int vs float, list vs tuple)
  • Process large files in chunks, not all at once
  • Use sys.getsizeof() to monitor memory usage
  • Delete large objects when no longer needed
  • Consider memory-mapped files for very large data

Key Takeaways

  • Bit is the smallest unit - represents 0 or 1
  • Byte = 8 bits - fundamental storage unit
  • Units scale by 1024 in binary (KB, MB, GB, TB)
  • Binary vs decimal causes confusion in storage capacity
  • Network uses bits, storage uses bytes - different units for different purposes
  • Python provides tools to measure and convert between units
  • Understanding units helps optimize memory usage and performance
