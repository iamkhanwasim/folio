What are Data Structures?

March 2020

Data structures are organized ways to store and manage data in a computer. They define how data is arranged in memory and what operations can be performed on that data. Choosing the right data structure directly impacts program performance and code clarity.

Every programming task involves working with data. Data structures provide the foundation for efficient algorithms by determining how quickly you can access, search, insert, or delete data. Understanding computational complexity helps evaluate which data structure best fits your needs.

Why Data Structures Matter

The same problem solved with different data structures can have vastly different performance:

  • Searching 1 million items in a list: O(n) - may check all items
  • Searching 1 million items in a hash table: O(1) - instant lookup
  • Finding minimum in unsorted list: O(n) - must scan all
  • Finding minimum in a heap: O(1) - always at root

Built-in Python Data Structures

Python provides several built-in data structures, each optimized for different use cases.

Lists

Lists are ordered, mutable sequences. They can hold elements of different types and are implemented as dynamic arrays.

# Creating and manipulating lists
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]

# Access by index - O(1)
first = numbers[0]

# Append - O(1) amortized
numbers.append(6)

# Insert at position - O(n)
numbers.insert(0, 99)

# Remove by value - O(n)
numbers.remove(3)

# Pop from end - O(1)
last = numbers.pop()

When to use Lists:

  • Need to maintain insertion order
  • Require fast index access
  • Primarily appending to the end
  • Need a mutable sequence

Tuples

Tuples are ordered, immutable sequences. Once created, their contents cannot be changed.

# Creating tuples
point = (10, 20)
rgb = (255, 128, 0)

# Access by index - O(1)
x = point[0]

# Unpacking
r, g, b = rgb

# Tuples are immutable - this raises an error
# point[0] = 15  # TypeError

# Can be used as dictionary keys
locations = {
    (0, 0): "origin",
    (10, 20): "point A"
}

When to use Tuples:

  • Data should not be modified
  • Need to use as dictionary keys
  • Returning multiple values from a function
  • Slightly faster than lists for iteration

Dictionaries

Dictionaries are unordered collections of key-value pairs. They provide fast lookups using hash tables.

# Creating dictionaries
student = {
    "name": "Alice",
    "age": 25,
    "grades": [90, 85, 92]
}

# Access by key - O(1) average
name = student["name"]

# Add or update - O(1) average
student["major"] = "Computer Science"

# Check if key exists - O(1)
if "age" in student:
    print("Age found")

# Get with default - O(1)
gpa = student.get("gpa", 0.0)

# Remove key - O(1) average
del student["age"]

When to use Dictionaries:

  • Need fast lookups by key
  • Mapping relationships (key → value)
  • Counting occurrences
  • Caching/memoization

Sets

Sets are unordered collections of unique elements. They are implemented using hash tables.

# Creating sets
fruits = {"apple", "banana", "orange"}
numbers = set([1, 2, 3, 2, 1])  # {1, 2, 3}

# Add element - O(1) average
fruits.add("grape")

# Remove element - O(1) average
fruits.remove("banana")

# Check membership - O(1) average
if "apple" in fruits:
    print("Found apple")

# Set operations
a = {1, 2, 3}
b = {3, 4, 5}

union = a | b           # {1, 2, 3, 4, 5}
intersection = a & b   # {3}
difference = a - b     # {1, 2}

When to use Sets:

  • Need to ensure uniqueness
  • Fast membership testing
  • Mathematical set operations
  • Removing duplicates from a sequence

Time Complexity Comparison

Common Operations:

  • List access by index: O(1)
  • List search: O(n)
  • List append: O(1) amortized
  • List insert: O(n)
  • Dict/Set lookup: O(1) average
  • Dict/Set insert: O(1) average
  • Dict/Set delete: O(1) average

Choosing the Right Data Structure

Questions to ask:

  • Do you need order? → List or Tuple
  • Will data change? → List (yes) or Tuple (no)
  • Need fast lookups? → Dictionary or Set
  • Need unique elements? → Set
  • Need key-value mapping? → Dictionary
  • Frequent insertions/deletions in middle? → Consider linked structures

Practical Example

# Problem: Count word frequency in text
text = "the quick brown fox jumps over the lazy dog"
words = text.split()

# Using a dictionary - O(n)
word_count = {}
for word in words:
    word_count[word] = word_count.get(word, 0) + 1

print(word_count)
# {'the': 2, 'quick': 1, 'brown': 1, ...}

# Find unique words - use set
unique_words = set(words)
print(len(unique_words))  # Number of unique words

# Maintain word order - use list
words_in_order = words  # Already a list

Key Takeaways

  • Data structures organize data for efficient storage and access
  • Different structures excel at different operations - choose based on your needs
  • Python's built-in types cover most common use cases
  • Time complexity matters - O(1) vs O(n) makes huge difference at scale
  • Lists for ordered mutable data, tuples for immutable
  • Dictionaries for key-value lookups, sets for uniqueness
  • Understanding trade-offs helps write efficient code
